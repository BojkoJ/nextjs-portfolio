# Security Policy

## Supported versions

This is a personal portfolio website. Only the latest commit on `master` (what
is deployed) is maintained.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

- Use GitHub's **[Report a vulnerability](../../security/advisories/new)** (private advisory), or
- e-mail **honzabojko@seznam.cz** with a description, steps to reproduce and the
  affected URL or file.

I'll do my best to acknowledge a report within about a week and to fix confirmed
issues promptly. Please give me a reasonable time to fix before disclosing
publicly. This is a personal project, so there is no bug bounty.

## Dependencies

Dependencies are pinned by `package-lock.json`, monitored by Dependabot and
checked with `npm audit` in CI.
